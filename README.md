# 🛒 Blinkit Sales Power-BI Analysis Dashboard

Welcome to the **Blinkit Sales Power-BI Analysis Dashboard** repository! 🚀

This project showcases an interactive business intelligence solution built with Microsoft Power BI to uncover insights into grocery sales, product performance, and outlet operations.

---

## 🚀 Project Overview

The **Blinkit Sales Power-BI Analysis Dashboard** uses BlinkIT grocery data to analyze business performance across product categories, outlet types, outlet sizes, and locations.

The dashboard enables users to analyze:

- Overall sales performance
- Average sales and customer ratings
- Number of items
- Sales by item type
- Sales by fat content
- Sales by outlet location
- Sales by outlet size and type
- Sales trends by outlet establishment year
- Item visibility and outlet performance

---

## 📊 Dashboard Features

### 🔑 Key Performance Indicators (KPIs)

The dashboard provides an overview of business performance through KPI cards:

- **Total Sales** – Total revenue generated from sales
- **Average Sales** – Average sales value
- **Number of Items** – Total number of items recorded
- **Average Rating** – Average customer rating

These KPIs help users quickly understand overall sales performance.

---

### 🥫 Item Analysis

The dashboard provides insights into product categories and their contribution to sales.

Users can analyze:

- Sales by item type
- Sales by item fat content
- Performance differences across product categories

This helps identify categories that contribute most to total sales.

---

### 🏪 Outlet Analysis

The dashboard explores sales performance across different outlet characteristics.

Key analysis includes:

- Sales by outlet location tier
- Sales by outlet size
- Sales by outlet type
- Sales by outlet establishment year
- Average ratings and item visibility by outlet type

These insights help compare outlet performance and identify business patterns.

---

### 📈 Sales Trend Analysis

The dashboard includes time-based analysis to explore sales patterns.

Users can examine:

- Sales by outlet establishment year
- Differences in sales across outlet establishment periods
- Performance comparisons across outlet categories

---

### 🎛️ Interactive Filters

The dashboard provides interactive slicers to explore the data dynamically.

Available filters include:

- **Item Type**
- **Outlet Size**
- **Outlet Location Type**
- **Metric Selection**

These filters allow users to focus on specific categories and compare business performance.

---

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Interactive dashboard development
- **Power Query** – Data preparation and transformation
- **DAX** – Measures and business calculations
- **Data Visualization** – Charts, KPI cards, tables, and slicers
- **BlinkIT Grocery Data** – Sales dataset

## 🧩 Data Model

The dashboard is built around a centralized BlinkIT grocery dataset.

### Dimensions / Attributes

- Item Fat Content
- Item Type
- Outlet Establishment Year
- Outlet Location Type
- Outlet Size
- Outlet Type
- Item Visibility

### Measures / Metrics

- Total Sales
- Average Sales
- Number of Items
- Average Rating

These attributes and metrics support interactive filtering and business performance analysis.

| Visualization | Purpose |
